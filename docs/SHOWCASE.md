# Interface gallery

[Back to the homepage](../README.md) · [Download the Viewer](https://github.com/kitomisaitichi-design/chatgpt-viewer/releases/latest)

Eleven actual-interface walkthroughs: three new v1.1.38 demos plus eight preserved v1.1.28 recordings. All use separate synthetic demonstration archives. Sample chat text, landscape studies and the audio tone are not personal content. Captures are 1600 pixels wide, with explanatory captions outside the interface; these are edited sequences of genuine UI states, not continuous real-time recordings. Open any animation for full resolution.

## Global table layouts — new in 1.1.38

Use the icon in the conversation header to switch **all tables** at once: Clean (ChatGPT-like borderless), Fit, Wide, Compact, Sleek or Expanded. Also expand or collapse every table in one action. Changes apply to tables formatted later as you scroll.

![Global table style menu and layout changes](media/interface-table-layouts.gif)

## Adaptive sidebar — new in 1.1.37–1.1.38

Set the sidebar size from 70–115%, or leave it on Auto. Bookmarks, Trash, size and Settings stay in a small icon dock, while secondary controls appear only when you open More.

![Normal, Small, Auto and contextual sidebar controls](media/interface-sidebar-density.gif)

## Recover original source links — new in 1.1.38

Article URLs preserved in JSON open directly. A citation containing only a saved reference ID cannot produce an article URL, but it offers the saved original ChatGPT conversation link when available.

![Saved citations and original conversation fallback](media/interface-source-links.gif)

*The screenshots use example URLs and fictitious conversation IDs. They demonstrate the actual Viewer interface, not live external ChatGPT pages.*
