# Offline Chat Viewer 1.1.30

This release combines the recent **structured-content renderer** improvements with fixes for slow/stalled deletion, account-scoped remote verification, and local Codex session removal. It builds on v1.1.29's source-aware opening and deletion workflows.

## ChatGPT-style rendering

- **Saved structured content:** Recognize nested ChatGPT layout markup (grids, rows, columns, cards, compact text and captions), saved Chart JSON, and Mermaid-style flowcharts with varying directions, nodes, labels, branches and feedback links. Ordinary code examples remain literal.
- **Flowcharts:** Bundle an offline Dagre layout engine to route directed edges. Expand graphs into an unclipped dialog with Fit, zoom controls and Close; collapse restores the original message.
- **Charts:** Preserve supplied data, series, categories, axis bounds and labels. Use subtler grids and native-like spacing, with functional expanded views.
- **Download lists:** Render saved linked-file collections as clickable document rows with descriptions, resolving links only to available local conversation files. Missing exports are reported as unavailable instead of producing broken links.
- **Tables and small print:** Better default fit for wide tables, smaller captions and metric-card subtext, without sacrificing existing table controls.

## Deletion and queue reliability

- **Already deleted online:** When an older saved ChatGPT conversation is absent online, perform **two separate, authenticated no-cache GET checks** for the same conversation and original account scope. Only matching, conclusive absence results permit local cleanup. A lone 404, network error, sign-in mismatch or 429 is not accepted as proof. No redundant remote delete is sent if both checks confirm absence.
- **Normal remote deletes remain fast:** Successful remote mutation still follows GET preflight → PATCH → GET verification, with matching acknowledgment and receipt reuse after interruption.
- **Source-sensitive choices:** Temporary chats, local/orphan records, native Codex JSONL and genuine ChatGPT-linked exports follow their respective local or account-scoped paths. Multiple export origins, shared sources and preserve-original choices are kept distinct.
- **Codex local removal:** Deleting a native Codex session no longer waits for every Codex process to exit. It validates and removes the **selected** session JSONL while other Codex sessions can stay open. A locked or changing selected file retries; unrelated workspace files are not removed.
- **Progress and connection:** Separate ordinary short browser pacing from genuine ChatGPT rate limits, avoid accumulating stale countdowns, fail promptly on missing or wrong-account connections, and allow previously verified remote deletions to finish their local work offline.
- **Recovery:** Verify local file hashes and ownership before removal; retain private recovery copies and exclusions that prevent removed sessions from being rediscovered. “Delete original” is not a permanent erasure of every recovery byte.

## Validation and installing

- Regression coverage includes already-missing remote chats, inconclusive and inconsistent remote responses, successful remote deletion acknowledgment, native Codex file-use retries, source-origin safeguards, structured rendering and browser pacing.
- The 1.1.30 GitHub Actions release workflow executes the Python suite and the expanded JavaScript suite before creating the portable Windows ZIP and SHA-256 file. Local pre-release tests and package verification are recorded separately from CI.
- Stop the prior Viewer before replacing application files. Preserve `.viewer-data`, your saved exports, preference store, backup archives, optional models, and the separate native login profile. The optional verified updater stages installation for next launch; it does not replace a running server.
