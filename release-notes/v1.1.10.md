# Offline Chat Viewer 1.1.10

Exported writing/document headers now render as titled cards with copy and expand controls, retaining the normal Markdown, LaTeX, table, code and citation pipeline. Expansion preserves the conversation's layout and restores the original card; copy keeps the source body. Fenced examples and malformed headers remain literal, and partial exports can render incrementally.

Locally saved native, Markdown/HTML and associated Library images now share a thread-wide gallery, including prompts outside the loaded message window. Lazy thumbnails open an enclosed viewer with wheel zoom, zoomed drag/pan, fitted horizontal swipe, arrow keys, Fit/0, plus/minus, Escape and original-prompt jumps. Repeated references share one image with preserved prompt occurrences. Library images with no saved prompt association are labelled and placed last, with prompt jumps disabled.

Metadata reuses the fingerprinted/coalesced source cache, invalidates on source/branch/manifest changes, and checks fresh catalog metadata on explicit viewer opens. Image decoding retains at most three elements and preloads only the next image. No recursive image-folder scans or eager whole-thread DOM rendering. Missing copies can be retried without conversation reindexing; remote image URLs are not fetched, and inline gallery delivery checks raster signatures and root-bounded paths.

Validation: 225 backend tests; all web JavaScript syntax checks; document/parser, rendering/cache and catalog checks. Isolated Edge exercised document expansion, preserved formulas/tables/citations and source-body copy, native thumbnails, unloaded-prompt jumps, duplicate open, refresh, keyboard and touch swipes, wheel zoom, pan without navigation, missing-file recovery, empty galleries, Library entry points, reduced motion and bounded decoded-image reuse. Source-only lifecycle audit found no additional actionable defects. Screenshots and installation/package checks are recorded separately.

Existing organization, preferences, original exports and backup scheduling/ZIP slots are preserved. The public portable excludes personal archives, fixtures and account-specific overrides. Image prompt order is limited by metadata actually saved by the exporter; no missing files or associations are invented. Cloud upload and unattended Windows scheduling were not re-tested in this renderer release.
