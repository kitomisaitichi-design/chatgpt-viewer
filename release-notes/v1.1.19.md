# Sidebar organization that stays together

- Organized view combines pins, bookmarks, native ChatGPT Projects, personal folders/categories, Chats, Work and Codex, without duplicate rows.
- Small organization control offers draggable priorities, keyboard up/down ordering, nested rules, visibility, counts, dates, density, initial list size and saved expansion.
- Pins use Show more so projects remain reachable. Native project and source-folder metadata remain distinct; json/session paths get readable presentation labels.
- Restore unambiguous missing native project names from saved metadata; sparse duplicate handoffs no longer erase richer links. No archive rescan or message reindex required.
- Existing native connection, queue ownership, attachments, source hashes and originals are preserved. No personal remote deletions are performed during release verification.

Keep .viewer-data and shared preferences when upgrading. Rollback: stop the viewer, restore previous app files and the matching private data backup; never restore an old deletion queue as running.
