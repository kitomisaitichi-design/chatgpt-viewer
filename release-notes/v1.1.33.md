# Offline Chat Viewer 1.1.33

Find a conversation by title without waiting for a message-body search. Ctrl+K now opens a title-first finder that shows cached local results immediately and supplements them with a metadata-only backend lookup.

- **Fast title navigation:** Exact titles and IDs, phrases, prefixes and word matches are ranked in order. Original titles remain searchable after renaming. Conservative typo suggestions appear only when literal matching finds nothing, and are labeled clearly.
- **Working keyboard controls:** Use Up/Down to choose and Enter to open; clear the query or close with Escape. Chat-type and category filters still apply. A separate Search message contents button opens the existing full-text modes.
- **Responsive requests:** Typing cancels outdated searches immediately. Late responses or errors cannot replace newer results or reopen a closed search. Pending, empty and failed deep searches have distinct visible states.
- **Less repeated work:** Sidebar filtering reuses normalized metadata, and updates are coalesced to an animation frame. Structured content avoids duplicate parsing and keeps a bounded, immutable extraction cache. Existing Markdown workers and progressive rendering remain in place.
- **Polished motion:** Short opacity/transform transitions on relevant panels and controls, with reduced-motion support. Results are not held back by an entrance animation.

## Verification

The local backend suite ran 323 tests with one skipped. All 12 JavaScript release suites passed, including new tests for title ranking, metadata-only database reads, cancellation, repeated Enter, clearing and closing. Browser checks covered Ctrl+K, keyboard opening, accents, original/renamed titles, typo labels, full-text search, refresh, a 120-card structured document, narrow layouts and reduced motion. GitHub release CI reruns the required suites before publishing.

On the same synthetic 1,000-chat browser demo, median input-to-matching-DOM-result time across three queries fell from 304.2 ms to 2.3 ms. A 50,000-row warm sidebar-filter benchmark fell from 41.0 ms to 20.2 ms. These are specific local measurements, not a guarantee for every archive or a measurement of total page paint.
