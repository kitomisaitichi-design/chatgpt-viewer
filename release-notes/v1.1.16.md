# Offline Chat Viewer 1.1.16 — Exporter resume repair

Fixes the optional bridge leaving the exporter folder ready without metadata, which caused **Cannot read properties of null (reading 'metadata')** when selecting **Resume backup**. Heartbeat queue lookup uses a separate folder handle; the installer repairs stale folder state. Compatible with **ChatGPT Exporter 2.4.12 and 2.4.13**.

## Install or update

Extract **Offline-Chat-Viewer-v1.1.16-Windows.zip**, then run **START-VIEWER.bat**. Keep the previous folder for rollback. Shared preferences migrate; preserve `.viewer-data` for an in-place update. In the deletion queue setup, update/reinstall the optional exporter bridge and refresh the exporter dashboard. A full extension update also needs Reload at `edge://extensions`. Reconnect and Resume the existing backup; do not reset its queue or remove saved files.

## Included features

- Green connection status; initial attempt plus two retries, then manual **Reconnect**.
- Asynchronous full/progress ZIP capture and queued Drive delivery, with content hashes and no duplicate unchanged ZIP slots.
- Read-only linked image/document previews, Markdown/LaTeX rendering and copy, search, independent ordering/type filters, bookmarks and reversible Trash.
- Native Codex discovery and distinct verified-deleted versus unavailable local-copy labels.
- Reviewed remote deletion uses the optional exporter scheduler and its rate-limit cooldown. Remote Library deletion is unsupported.
