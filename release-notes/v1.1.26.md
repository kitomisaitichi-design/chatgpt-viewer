Adds isolated HTML previews, streamed audio/video playback (MP3, MP4, OGG, WAV, M4A including MA4 filename alias, and browser-supported variants), and built-in MIDI synthesis with play/pause, seeking and volume. Media support depends on the file codec; unsupported files retain Open original. MIDI supports standard format 0/1 with PPQ timing, bounded preview and synthetic instruments.

Document previews reuse formatted Markdown and search snapshots; PDF extraction is cached during preview. Adds first-message navigation and translucent image navigation strips with wrapping and unavailable-image skipping. Saved image_group markup renders as styled cards with honest unavailable/source states; caption and Link markup is readable. Redundant media references represented by attachment cards are hidden in the reader, while original source and code examples are preserved. External image searches are not fetched automatically; offline previews use saved files.

Personal data, preferences, native connection and selected local copies are preserved.

Theme-aware custom media controls add seeking, volume/mute, playback speed, repeat, previous/next and a real thread media list. Video supports fullscreen and picture-in-picture where available. Audio and MIDI meters use real playback analysis; no invented album artwork, chapters or waveform data.
