# Offline Chat Viewer 1.1.29

This Windows portable update completes native opening of indexed source files from a message and ships the stable chat opening, scanning and deletion behavior verified after the v1.1.28 rollback.

## New and improved

- **Clickable indexed source files:** Follow `.jsonl`, `.json` and `.md` references to their parsed conversations. Referenced files already attached to the current conversation open in the built-in document pane instead of silently reopening the chat. Windows absolute paths that the Markdown sanitizer formerly rendered as inert links are now recognized without allowing arbitrary filesystem URLs. When more than one indexed conversation matches a filename, choose which to open.
- **Native JSONL text preview:** Available `.jsonl` and `.ndjson` attachments are recognized as text, with the existing bounded preview, document search and **Open original** action.
- **Source-aware deletion:** Temporary, local, linked and native conversations use their recorded source provenance when choosing local removal, preservation, and any applicable remote action. Shared companions and unrelated files remain intact.
- **Stable chat workflows:** Old saved chats stay readable; new exports are discovered on rescan; Trash, restore and confirmed local deletion behave consistently in isolated regression fixtures.
- **Library file integrity:** On delivery, a saved file with a recorded SHA-256 is checked against that checksum, including when the file has the expected size; mismatches are rejected.

## Validation and installation

- All 299 repository Python tests passed (one skipped) before the release bump. Isolated rollback and deletion fixtures cover old-chat reading, rescanning, Trash, restore, local removal and preservation. The Library checksum regression is covered by a separate recovery fixture.
- The exact original failing JSONL link was clicked and its locally available trace opened successfully as readable text in the running Viewer. Its preview is bounded; the original-file link remains available.
- GitHub Actions runs Python and JavaScript tests before publishing the versioned ZIP and matching SHA-256 checksum. The ZIP bundles the offline runtime and renderers, without user archives or credentials.
- Stop the existing Viewer process before replacing program files. Preserve `.viewer-data`, backups, models, the separate shared preference store and the native login profile. Alternatively, use Settings → Viewer updates to stage the verified release for installation on next launch if silent updates are enabled.

The original eight homepage UI walkthroughs were captured in 1.1.28 with a demonstration archive; they remain representative of the same viewer interface and have not been relabeled as new 1.1.29 captures.

Known limitations: An unusually long exact phrase crossing search-index chunk boundaries may be missed by archive-wide search even though in-conversation Find locates it. A completed browser-companion check can be reused during its current deduplication interval. Neither is represented as fixed in this release.
