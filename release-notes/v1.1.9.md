# Offline Chat Viewer 1.1.9

Fixes backups failing with “attachments/library-catalog.html changed before packaging” while ChatGPT Exporter is running. Packaging reads verified captured copies rather than reopening live files. Unstable files receive bounded attempts and a durable background retry; verified captures and the last completed ZIP survive interruptions. The backup panel shows waiting and retry state.

Unchanged source files reuse captured bytes, unchanged backups reuse completed ZIPs, and changed backups atomically replace the selected full/progress slots. ZIP contents retain original paths, cross-linked indexes, hashes and settings. Captures are per-file over an interval, not a transactional snapshot of the whole exporter; they need additional disk space. Files continuously changing during their capture delay completion rather than being silently omitted.

Original exports, existing settings and source provenance are preserved. The public portable contains no personal archive, account overrides or test fixtures. Google Drive for desktop performs cloud synchronization after the viewer verifies the local copy.

Validation: 213 backend tests, JavaScript syntax and renderer/catalog checks; source mutation/retry/restart/cancellation, damaged captures and unchanged ZIP regressions. Isolated Edge exercised empty input, double submission, live fixture writes, refresh persistence, automatic completion and completed-ZIP mirroring. Public package integrity/private exclusions are recorded with the release checks. Actual cloud upload, unattended scheduled execution and a complete multi-gigabyte personal archive backup are not verified by these local tests.
