# Offline Chat Viewer 1.1.36

- Replace the multi-row sidebar selection toolbar with a compact, always-one-row Select chats / Tools control.
- Show selected count in the compact control; move bulk actions and Codex subagent controls into an expandable panel.
- Allow the panel to be dragged by its heading or resized from its lower corner, constrained to the visible screen.
- Keep the chat list from jumping downward when selections change or the actions panel opens.
- Preserve Ctrl/Command-click, Shift-click, visible-only inversion, hidden subagent selection and reviewed deletion/backup workflows.
- Clicking away or pressing Escape closes the tools without discarding the selection; Escape again clears the selection.

The update changes only the selection interface; no conversation data or backup settings are migrated.
