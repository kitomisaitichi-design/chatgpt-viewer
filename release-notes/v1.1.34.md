# Offline Chat Viewer 1.1.34

- Open a Codex conversation's recorded home folder and any conversation's source folder.
- Render explicitly linked local directories as folder cards instead of unsupported attachments.
- Ctrl/Command-click toggles chats, Shift-click selects a visible range, and Ctrl+Shift adds a range.
- Select all visible, invert visible selection, clear selections and queue the selected chats through the existing deletion review.
- Hide Codex subagent conversations by default, remember the visibility preference, or select all matching subagents even while hidden.
- Keep original source records, workspace files and existing deletion choices intact.

See [Selection and folders](../docs/SELECTION-AND-FOLDERS.md) for selection scope and keyboard behavior. Backend, renderer and UI verification are recorded in the accompanying local verification report; production conversations are not deleted during checks.
