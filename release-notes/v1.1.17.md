# Offline Chat Viewer 1.1.17

Adds an independent browser connection for reviewed ChatGPT deletion, optional exporter ownership handoff, durable request leases, revision checks and recovery. No exporter account index is required. Native Codex deletion waits for Codex to close, retains a readable recovery copy and persists rediscovery exclusions. Native ChatGPT Projects are distinct from Disk folders and local Categories. Queue/status controls include reconnect, cooldown countdown, pause/stop and progress following.

Extract the ZIP and run START-VIEWER.bat. Keep .viewer-data when updating in place. For remote actions, load the privately paired Browser connection folder from the viewer's Connect browser setup and refresh your signed-in ChatGPT tab. The optional Exporter 2.4.12/2.4.13 adapter requires extension reload after upgrading.

Remote Library deletion is unsupported. Original chat files/content hashes and shared attachments are preserved; local cleanup retains recovery. Codex-owned databases are not edited. Live authenticated deletion is not run during release checks; browser/HTTP contracts use isolated fixtures. See README for installation and rollback.
