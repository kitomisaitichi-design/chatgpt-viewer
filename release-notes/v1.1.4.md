# Offline Chat Viewer 1.1.4

Adds a Files & Library browser interoperable with [ChatGPT Exporter 2.4.1](https://github.com/kitomisaitichi-design/chatgpt-exporter/releases/tag/ChatGPT2.4.1).

- Search saved chat attachments and Library files; filter saved/manual/attention items or the selected chat.
- Download local files and open their source chat. Raster images can open inline; exported HTML/SVG/code downloads as files.
- Import manually downloaded copies, including Library files at or above 10 MB, into the exporter's expected backup paths. Size/checksum checks and existing-copy protection apply.
- Catalog changes and local file availability refresh without rebuilding message indexes. Large local downloads stream in bounded chunks.
- Existing organization, preferences, indexes and backup/Drive workflows remain available.
- Backup ZIP compression now supports Python 3.10–3.12 as well as the bundled Python 3.13. Windows scheduler tests run on Windows.

Keep .viewer-data when replacing app files, then restart START-VIEWER.bat. Select your exporter backup folder with Export folders, then open Files & Library. Older exporters can show existing attachments; update to 2.4.1 for manual import paths.

Windows x64 Python is included. No package installation is required for standard use. SHA-256 is supplied beside the ZIP. Validation: 162 backend tests and exporter-to-viewer integration in Edge 154, including a manual 10,000,000-byte import and an intact saved-file download. No live-account Library API test was performed.
