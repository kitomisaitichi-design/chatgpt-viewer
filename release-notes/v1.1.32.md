# Offline Chat Viewer 1.1.32

Saved declarative tables now have working local sort, filter and Copy controls. Responsive newspaper-style layouts can mix those tables with text, statuses, bars, charts, expandable notes and copyable content.

- **Dynamic tables:** Render structured rows or saved JSON columns/rows; preserve header labels, links and rich status cells. Numeric and natural-text sorting cycle back to original order. Filtering is local, and Copy exports all matching rows as TSV.
- **Bounded rendering:** Page through 100 rows rather than creating a huge table DOM. Wider than 64 columns shows a clear preview limit while retaining complete Layout source.
- **Mixed columns:** Support newspaper/column/article/section layouts, headings and paragraphs; desktop columns collapse to one at narrow widths.
- **Status styling:** Green `[OK]`, warning/error/pending labels, badges and icons retain their actual supplied text and symbols. Colors adapt to the theme; saved statuses are not presented as live verification.
- Retain 1.1.31's comparison/progress bars, copy controls, keyboard tabs, disclosures, nested charts and unknown/malformed-content preservation.

The dynamic components use the existing renderer and browser primitives, with no new dependency. Literal code, legacy media, normal Markdown tables and attachment handling retain their existing paths.

## Verification

JavaScript regression checks cover JSON/structured rich tables, numeric sorting, clearing/no-result filters, copied labels/data, pagination, mixed layouts and status preservation alongside the 1.1.31 controls. Actual browser checks confirm table sorting, filtering, copied TSV, responsive columns and theme-aware statuses. The unchanged backend suite most recently passed 320 tests with one skipped; GitHub release CI reruns the required backend and JavaScript checks.

New component examples are documented in [supported dynamic content](../docs/DYNAMIC-CONTENT.md). They do not imply that every ChatGPT export uses one identical undocumented serialization.

Use the complete portable ZIP or the existing verified update flow. Retain exports, preferences, `.viewer-data` and native login profiles when updating.
