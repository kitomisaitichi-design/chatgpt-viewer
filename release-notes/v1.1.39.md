# Offline Chat Viewer 1.1.39

- Add a small iPhone-inspired message scrubber at the right edge of conversations. Its **19 short horizontal black-and-white dashes** animate with scroll position; it is not a full-height scrollbar.
- A translucent hover preview shows the selected message, its role and position. Click, drag, or use the keyboard to jump anywhere in the thread.
- Index messages across the full archived conversation, not just currently loaded HTML pages. Jumping to an unloaded position fetches that page safely.
- Hide the redundant native scrollbar when the wide-screen scrubber has enough whitespace; on smaller screens the native scrolling remains available.
- Visually group consecutive ChatGPT commentary into a compact progress sequence, with one model/effort badge per distinct value in the group. Keep original message order, IDs, copying and deep links intact.

The new read-only timeline index uses bounded snippets from the local archive. It does not alter or migrate conversations or backups.
