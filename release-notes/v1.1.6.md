Adds a compact catalog search, combined read/project/pin/title/date filters, sidebar dates, conversation metadata, quick rename, and keyboard navigation. Read status is saved across versions; newer exported conversations become unread. Type tabs, pins, folder order, manual placements, message search and rendering are preserved.

Controls are independently implemented with inspiration from ChatGPT Triage. Its remote query/delete queue is not included. No private archive, preferences or example chats ship in the ZIP.

Validation: backend suite, JavaScript syntax, renderer checks, filter/date/read/order regression checks and isolated browser checks. Keep `.viewer-data` when replacing app files.
