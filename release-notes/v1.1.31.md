# Offline Chat Viewer 1.1.31

Newer saved components can now live inside cards and grids without making the entire layout disappear. This update also adds slim labeled bars and local controls that fit the current Viewer theme.

- Render labeled comparison, meter and progress bars with the original limits and descriptions. Missing values keep their qualitative text and do not receive an invented track or score.
- Render copyable text, tabs with keyboard navigation, expandable notes, explicit copy buttons and saved URL actions.
- Support Chart components nested inside grids and boxes, using the existing chart controls and supplied data.
- Honor bounded layout sizing/spacing/background attributes, including empty boxes used as thin visual bars.
- Preserve unknown wrappers and malformed component source. Exported expressions remain inert, and literal code examples stay literal.
- Avoid adding a second code toolbar to a component that already has its own Copy control.
