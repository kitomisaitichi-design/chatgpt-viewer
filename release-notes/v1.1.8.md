# Offline Chat Viewer 1.1.8

Exporter 2.4.10 compatibility and reliable queued ZIP delivery.

- Full and progress ZIPs finish locally even when Drive is unavailable. Completed ZIPs remain downloadable, and delivery retries use their saved hashes without rescanning an offline source.
- Persistent, bounded backup/copy queues coalesce repeated requests with the same delivery policy. Local-only work stays separate from uploads. Queued and interrupted work recover across restarts/upgrades; cancellation invalidates active work across processes.
- Failed delivery starts retrying after two minutes and backs off to six hours. Changed destinations and ZIP contents require an explicit new action. Queue status, paused delivery and a Retry control are visible in Backups & Drive.
- Optional automatic backup after exporter manifest changes settle for two minutes, using the existing idle/power conditions. Only known manifest stats are checked between periodic backups; large archives are not recursively rescanned on every tick.
- Nested exporter roots and Library-only handoffs are found. Current large exporter metadata is supported up to 128 MiB, with shared fingerprinted, bounded metadata caching that drops exporter logs/internal job state.
- Duplicate native JSON conversations prefer saved server update dates over local rewrite times. Display metadata dates stay separate from the timestamp of the imported body; older upgraded caches recover source dates from bounded headers.
- Existing Drive detection/autofill, content selections, original folder paths, cross-link indexes, SHA-256/save-state tables, pins/aliases/trash, preferences and rendering remain available.

Validation: 206 backend tests, all browser JavaScript syntax checks, renderer and catalog checks. Isolated Edge checks cover empty source input, double submit, local ZIP creation, existing ZIP copying, pending delivery across refresh and automatic copy after an unavailable test destination returns. Read-only inspection of the actual Exporter 2.4.10 archive found both outer/nested roots and loaded its 43 MB handoff/59 MB state without limit warnings. Some conversations remain missing locally; the viewer reports them rather than inventing files.

Cloud upload and an unattended Windows idle run were not exercised. Google Drive for desktop reports its own cloud-sync completion. Automatic backups remain opt-in. The portable ZIP excludes private archives/preferences, account-specific ground truth and test conversations. Keep `.viewer-data` when updating; back up app files before replacement.
