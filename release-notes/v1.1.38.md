# Offline Chat Viewer 1.1.38

- Add a top-right **All tables** icon and menu for Clean (ChatGPT-inspired borderless), Fit, Wide, Compact, Sleek and Expanded table layouts.
- Apply the chosen layout simultaneously to all loaded tables and to tables lazily formatted later. Save the chosen layout in viewer preferences.
- Provide **Expand every table** and **Collapse every table** actions scoped to the current conversation. Normal per-table Copy/Expand buttons remain available.
- Streamline borders, toolbar chrome, row spacing and reading width according to selected table style.
- When a saved citation lacks an external URL, check exact message source metadata and display any genuine saved URL as a normal clickable source. If none was exported, provide an **Open original in ChatGPT** link when the conversation's original URL was saved, plus Copy reference ID.
- Never manufacture an article URL from a citation reference ID. Original ChatGPT citation pages may have richer source metadata than exported files.

These are display and navigation changes only. No conversation data or backup preferences are modified or deleted.
