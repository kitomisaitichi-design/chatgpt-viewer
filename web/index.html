Sign in using Google Drive for desktop. Choose a folder it syncs—your mirrored My Drive, streamed Drive, or a local folder configured with “Sync with Google Drive”.
The viewer copies completed ZIPs here. Google’s desktop app handles the upload and reports its sync status; no client JSON or API authorization is needed in this viewer.

One-time Google connection setup
Google requires a registered Desktop app. In Google Cloud, enable Google Drive API, configure Google Auth Platform for your account, and create an OAuth client of type Desktop app. Download its JSON and import it above. See Google’s setup instructions.
The connection can read folder names and edit backups created by this app. Google credentials are protected by your Windows account and stay outside the shared package. A Google app left in Testing may require reconnecting after its temporary authorization expires.
